01 · Identidad visual

La interfaz toma como referencia los dos colores protagonistas del logo institucional: azul para estructura, confianza y navegación; rojo para acciones destacadas y estados de atención. El blanco y los grises funcionan como soporte para mantener legibilidad y una estética escolar/tecnológica.

Azul institucional

Color estructural. Usar en encabezados, navegación, botones primarios, links y elementos que representen acciones principales.

Rojo institucional

Color de énfasis. Usar con moderación en acciones importantes, alertas, disponibilidad visual y detalles de identidad.

13 · Reglas de uso visual

Sí hacer

  • Mantener azul como color estructural.
  • Usar rojo para énfasis y situaciones críticas.
  • Usar estados con texto + color, no solo color.
  • Conservar Barlow en toda la interfaz.
  • Mantener componentes redondeados y espaciado consistente.
  • Priorizar lectura rápida en la PWA.

Evitar

  • Usar rojo como fondo dominante de toda la aplicación.
  • Mezclar muchas familias tipográficas.
  • Usar emojis como iconografía principal en producción.
  • Mostrar información administrativa sensible en la PWA.
  • Crear botones con demasiados estilos distintos.
  • Depender únicamente del color para comunicar un estado.
